# site

## Книги: защита текста

Текст книг в `knigi/<папка>/chapters.js` хранится зашифрованным (`window.BOOK_ENC`), читалка `assets/reader.js` расшифровывает его на экране.
После добавления или обновления книги обязательно запустить:

    python3 tools/protect_book.py knigi/<папка>/chapters.js

Скрипт превращает открытый `window.BOOK_TEXT = [...]` в зашифрованный. Читалка понимает оба вида, но открытый текст легко скачать целиком.
В читалке отключены выделение, копирование, контекстное меню и печать, на тексте полупрозрачный водяной знак,
а когда окно неактивно или нажата клавиша снимка экрана, текст размывается.

## Аккаунты читательниц

`assets/account.js` подключён в `<head>` каждой страницы: кнопка «Войти» в шапке, вход по имени и паролю,
код восстановления вместо почты. Всё, что страницы пишут в localStorage с ключами `oskolki-*`, `pos-*` и `reader-settings`,
автоматически сохраняется в аккаунт (база Supabase, проект oskolki). Таблицы и функции базы — `tools/supabase_accounts.sql`.
Новым страницам достаточно подключить скрипт и хранить прогресс под ключом с префиксом `oskolki-`.

## Картинки героев для игры

- `tools/cutout.py вход.jpg igra/img/имя.webp 760 32` — вырезает героя без ореола старого фона
  (маска rembg + матирование pymatting + очистка цвета края). Последнее число — ширина полосы очистки края
  (32 для картинок с цветным сиянием за головой, 18 для белого фона).
- `tools/align_sprite.py папка_с_вырезанными igra/img имя-эмоция ...` — подгоняет эмоции и наряды под базовую картинку героя.
- `tools/outfits.py igra/img` — перекрашивает свитер Ани и худи Артура для гардероба (для базовой картинки и всех эмоций).
